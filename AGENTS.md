# Portfolio instructions for Codex and Claude

Use this shared file for repository guidance. Claude Code can import it from
`CLAUDE.md`.

- Keep the portfolio in English. Use the positioning of a technical operations
  leader with automotive experience and AI-assisted application development.
- Edit public facts in `content/portfolio.json`, rendering in
  `scripts/build.py`, and styles and interactions in `src/`.
- Include only owner-approved material. Review content beyond case study
  metadata, including timeline entries, metadata and CV text.
- Keep all confidential evidence outside this repository. This includes raw
  CVs, assessment reports, third-party personal data, customer data and
  credentials. Use LinkedIn as the only personal contact link.
- Distinguish completed career outcomes, ongoing development, independent
  conceptual work and transferable expertise. Autonomous mobility is an
  interest. Publish additional metrics only after the owner verifies their
  basis and explicitly approves them.
- Run `python3 scripts/build.py` and `python3 scripts/check.py`. For UI changes,
  inspect mobile and desktop layouts, keyboard behavior and both color modes.
- Open changes for review. Merge and deploy only with owner approval.
